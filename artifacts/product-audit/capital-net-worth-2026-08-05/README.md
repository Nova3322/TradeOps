# 资金净值看板复核（2026-08-05）

## 真实根因

- 图中最大的生产只读变化是 Binance 约 `$0.0045`（`0.04%`），并非资金被划走或缺失值补零。旧纵轴把这类小波动过度放大，容易看成突然下跌。
- 旧画布压缩密集历史点时不断替换已保留点，连续区间在窄屏会塌成末端圆点；断档起点也可能被后续点覆盖，造成错误连线。
- 断档阈值曾复用 30 分钟风险事实有效期。资金风险是否仍可采信与图表是否应跨缺口连线是两个不同语义，现已分离。
- 顶部总额不可用但单线存在并不矛盾：当前 Vault 没有生产事实，所以三方汇总必须为不可计算；Binance 与 Hyperliquid 单项历史仍可保留。

## 最终行为

- 固定且仅有 Binance、Hyperliquid、Vault、三方汇总四条可开关曲线。
- 默认展示最近 6 小时；断档按各来源实际采样节奏的 3 倍判断，并设与配置同步周期一致的最低阈值，不再使用风险 TTL 连线。
- 三方汇总只使用 60 秒内对齐的三方事实；缺失、过期、时间错位和断档均不补零、不强连。
- 小于 100 USD 统一四位小数，其余两位；卡片、图例、坐标轴和悬停均使用同一 USD 格式。
- 每个来源展示最后更新时间、距今时长、当前有效窗口和只读数据源。接近过期的数据会明确预警。
- 纵轴至少保留 0.05% 观察范围，同时显示绝对变化和百分比；小额波动仍可判断，也不会把单个像素误读成资金崩跌。
