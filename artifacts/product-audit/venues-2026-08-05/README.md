# 交易账户验收（2026-08-05）

## 审计范围

- 页面：`/venues?venue=BINANCE`、`/venues?venue=HYPERLIQUID`
- 目标：区分当前事实、历史快照、只读连接、历史补全和交易执行边界。
- 权限：系统管理员、普通创建者、独立审核人、资金管理员、只读用户、禁用成员；另核对后端六身份集成矩阵。

## 发现与修复

1. 页面曾直接显示内部 `acct-1`，且两个交易所看起来像同一账户。现改为“默认账户 + 交易所 + 单账户模式”，内部标识仍只用于服务端查询。
2. Hyperliquid 页面曾写成“核心市场”，但实际已保存 `xyz:*` HIP-3 成交。现明确展示“核心市场 + HIP-3（xyz）”。
3. 历史补全受限时，页面仍宣称成交与资金费完整同步。现只承诺余额、仓位和当前委托更新，并将已保存历史标成不完整。
4. 原始上游错误码占据状态卡。现展示用户可理解的阻断和下一步，技术分类折叠保留。
5. 页面没有说明执行底座。现明确 Freqtrade worker 边界，并持续说明本页不能下单。
6. 交易账户表格补充手机端横向滑动提示；当前委托和历史订单继续分开统计。

## 当前运行结果

- Binance：只读连接正常，账户事实新鲜；无当前仓位、无当前委托，历史订单不计入当前委托。
- Hyperliquid：本轮上游只读接口限流，页面只展示最后快照并明确不可作为实时交易依据；HIP-3 范围仍可诊断。
- 外部探针在有限等待后仍为限流，未伪造恢复结果。
- 未执行下单、资金、签名或广播。
