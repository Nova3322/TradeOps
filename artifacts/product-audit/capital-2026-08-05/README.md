## 本轮根因与收敛

- 顶部不可汇总与已有单线并不矛盾：当前 Vault 没有生产事实，后端因此拒绝三方汇总；Binance 和 Hyperliquid 的有效历史仍可单独展示。
- 末端下跌来自 Binance 只读历史中的真实变化。当前样本最大单次下降约 `$0.0045`（`0.04%`），不是补零；页面现在明确提示纵轴会自动缩放，避免把放大的小波动误判成资金骤降。
- 原画布不会在视口变化时重绘，导致桌面切换手机宽度后比例和刻度被压缩。现已用宽度观察器重绘，390 px、430 px 和桌面位图宽度均与 CSS 宽度一致。
- 最近变化不再跨越断档比较；页面显示历史覆盖时间和断档数量，断档不会连线。
