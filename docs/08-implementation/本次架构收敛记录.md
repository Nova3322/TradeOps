### MERGE

- 通用 IAM/判定平台并入 `User`、`RoleAssignment` 和直接 RBAC 判断；
- Proposal current/version/history 并入 Proposal 当前状态、版本和 Approval；

- Order current/history/execution projection 并入 OrderIntent 当前状态和 VenueOrder/VenueFill；
- Campaign 经济、成交、目标和减仓链并入 Campaign 当前字段、场所成交和纯计算；

- sender scope/state/history/claim 并入一张 `SenderLease`；
- 场所 snapshot/projection/input link 并入当前场所事实表和普通查询。

- 幂等只保留请求摘要、回执和 PostgreSQL 原子事务；
- Capability Gate 只保留启用/禁用、原因、操作者和时间；
- 指标只覆盖 DB、风险拒绝、意图状态、对账、fencing 和保护异常；
- 测试围绕业务不变量、事务、幂等、对账和端到端流程组织。
