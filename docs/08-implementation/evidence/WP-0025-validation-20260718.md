## 3. 结果判定

1. 最终预检不再把 active giveback/cost 错归为 base Heat，也不再将两项固定写零。
2. 分解数据随 reservation 不可变冻结；动态 bucket 仍由同一 Ledger/Exposure 状态机守恒。
3. 部分成交、取消、Unknown 和释放不会重复计算或遗失 active loss component。
4. 新增分量本身的 canonical 定价、保护和费用真源仍未绑定，现实资金能力继续关闭。
