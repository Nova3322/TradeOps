### 2.2 能力注册与完整性

测试确认：

- 只有 `venue-capability-catalog-service` 的 INTERNAL 命令可注册；
- 同一幂等命令重放为 `ALREADY_PROCESSED`，只产生一行、一个 audit 和一个 outbox event；
- record/evidence hash 错误在写入前被拒绝；
- trigger/order/evidence 数组必须 canonical sorted unique；
- SHADOW-only、`real_funds_eligible=false` 由模型与数据库双重限制；
- 直接 `UPDATE` 返回 `instrument_protection_capability_records is immutable`；
- exact scope/catalog/template version 不能重复，Catalog composite FK 不能伪造。

### 2.3 Fail-closed capability

专项测试覆盖：

```text
missing exact record                  -> PROTECTION_CAPABILITY_RECORD_NOT_FOUND
expired record                        -> PROTECTION_CAPABILITY_OUTSIDE_VALID_WINDOW
bad record hash                       -> PROTECTION_CAPABILITY_INTEGRITY_FAILED
status != CERTIFIED                   -> PROTECTION_CAPABILITY_NOT_CERTIFIED
native protection unsupported         -> NATIVE_PROTECTION_UNSUPPORTED
conditional order unsupported         -> CONDITIONAL_ORDER_UNSUPPORTED
reduce-only unsupported               -> REDUCE_ONLY_PROTECTION_UNSUPPORTED
partial-fill protection unsupported   -> PARTIAL_FILL_PROTECTION_UNSUPPORTED
replacement unsupported               -> PROTECTION_REPLACEMENT_UNSUPPORTED
adapter/credential/worker scope drift -> PROTECTION_CAPABILITY_SCOPE_MISMATCH
```

Protection validator 保留详细原因；Risk Engine 在 proposal 与 final precheck 均转换为耐久
`PROTECTION_UNAVAILABLE` DENY，数量为零、有效期等于 decision time，不创建 OrderIntent 或 Reservation。
ALLOW 决策的 `valid_until` 另由 exact capability validity 收紧。

### 2.4 决策绑定

ALLOW 集成场景断言：

- Risk/Execution decision 的 record ID、position-management template version 和 record hash 与能力行一致；
- composite FK 指向 immutable exact capability 记录；
- input snapshot 保存 validator snapshot，decision 保存 ID/hash/evidence/reason；
- proposal 和 final precheck 都不再读取 caller protection boolean。

## 5. 结果判定

1. 调用方不再能以布尔值声称具备原生保护能力；v6 和旧字段均失败关闭。
2. Proposal/final precheck 从同一 immutable exact 记录独立验证 Catalog、账户、凭证、worker 和保护模板。
3. missing、过期、篡改、状态不可用、能力不全和 scope drift 均不能增加风险。
4. 能力记录与决策绑定可复算、不可原地改写，迁移不会静默删除历史事实。
5. 本包不构成真实场所认证、保护发送或实盘能力；三项现实能力门继续为 `DISABLED`。
