## 1. 验证范围

- exact-scope current protection SQL view 与只读 Pydantic 查询合同；
- event time 优先于到达顺序、最大事件时间冲突失败关闭；

- view read-only、迁移往返、schema drift、readiness 与现实能力门；
- 格式、lint、strict Mypy、全量测试和覆盖率。

新增场景实际通过：

```text
unique CONFIRMED + exact current position -> CONFIRMED/FRESH
latest DEGRADED                       -> UNKNOWN / SOURCE_DEGRADED
missing scope                         -> UNKNOWN/MISSING / SOURCE_MISSING
fresh source beyond max_age           -> UNKNOWN/STALE / SOURCE_STALE
same max event time with two facts     -> UNKNOWN / MAX_EVENT_TIME_COLLISION
protection references older position  -> UNKNOWN / POSITION_NOT_CURRENT
direct UPDATE view                     -> PostgreSQL cannot update view
```

confirmed 样例：

```text

covered quantity              = 0.5
uncovered quantity            = 0
worst active trigger price    = 49900
source position snapshot      = current position source snapshot
venue native / reduce-only    = true / true
replacement in progress       = false
```

所有 UNKNOWN 断言均验证 trigger、覆盖量和 source position binding 不可用，而不是返回零。
