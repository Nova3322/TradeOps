# WP-0027 验证证据（2026-07-18）

## 1. 验证范围

- cost-stress policy 必填、无默认、未知字段拒绝与 source ref 非空；
- caller-reported cost 字段从 v3 请求移除并 fail-closed；
- fee、stop penetration 和方向性 adverse funding 三项规范计算；
- 有利资金费不计为预期收益，也不形成负 cost；
- base、giveback 和 cost 向上取到 18 位数据库精度；
- trade、authorization、reservation、Ledger、七层 scope planned allocation 共用同一增量；
- scope stress 低于 canonical planned loss 时拒绝；
- v1/v2 命令与错误 v3 schema 拒绝；
- proposal/final decision JSON 保存模型版本和三项 cost 明细；
- 部分成交、Unknown、零成交释放、add 与 durable exposure 回归；
- 格式、lint、strict Mypy、全量测试、覆盖率和 schema drift。

按用户特别约束，未调用 Codex Security 或任何 Codex Security 审计 Skill、插件、模块。

## 5. 结果判定

1. 调用方不再能提交 cost 结果；Risk Engine 从不可变、hash 绑定的策略参数派生三项成本。
2. 没有 cost policy 或证据引用时不能形成有效风险策略，没有生产默认值。
3. 有利 funding 不会扩大风险容量，所有新增金额以 18 位保守精度进入审计与 reservation。
4. 真实参数、giveback 真源和 scope stress 场景仍未关闭，现实资金能力继续关闭。
