## 3. 被拒绝的错误建模

测试曾尝试构造 `LONG mark=109 / active stop trigger=110` 的 canonical protection。Venue normalization 按
既有不变量拒绝：

```text
VENUE_PROTECTION_TRIGGER_PRICE_INVALID
active protection trigger prices must remain on the protective side of current mark
```

因此最终实现没有把非法 active protection 状态伪装成 `HARD_STOP` 候选。原生 stop 保持场所独立执行；
本工作包只对保护健康失败生成系统风险退出候选。
