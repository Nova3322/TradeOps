## 5. 结果判定

1. 历史 plan snapshot 不再等同于当前有效计划。
2. target 新版本或 validity 过期会明确要求重新准备。

4. 本包没有 replacement、claim、OrderIntent 或发送能力，不构成实盘就绪证明。
