# WP-0049 验证证据（2026-07-18）

## 1. 验证范围

- 服务端解析 current-position binding hash 与 quantity；
- 真实 `0.5` current quantity 上的 REDUCE 与 HOLD；
- 调用方 binding/quantity substitution 拒绝；
- stale canonical position 在仲裁前失败关闭；
- 全量回归、branch coverage、静态检查、readiness 和现实能力门。

按用户明确约束，未调用、启用或建议 Codex Security，也未使用任何 Codex Security 审计 Skill、插件或模块。

## 2. 专项验证

```text
tests/integration/test_campaign_target_position.py
3 passed in 3.21s
```

服务端绑定成功：

```text
canonical current_quantity=0.5
candidate target_quantity=0.25
decision current_quantity=0.5
decision target_quantity=0.25
decision reduction_quantity=0.25
action=REDUCE
reduce_only_required=true
```

相同 fresh position、无候选时返回：

```text
current_quantity=0.5
target_quantity=0.5
action=HOLD
```

失败场景：

```text
candidate binding hash != server-resolved binding hash
  -> TARGET_POSITION_CANDIDATE_CONFLICT

candidate target=0.6 while canonical current=0.5
  -> TARGET_POSITION_CANDIDATE_CONFLICT

canonical current position exceeds TTL
  -> CAMPAIGN_CURRENT_POSITION_UNAVAILABLE
```

## 5. 结果判定

1. target-position arbitration 的 current binding/quantity 已由服务端 fresh canonical position 提供。
2. 调用方无法用伪造 current quantity 把持平或扩仓 target 包装为减仓。
3. position stale/unknown 时不会产生 HOLD/REDUCE/EXIT 假结果。
4. 本包仍不是 durable 或可发送退出链，现实能力没有变化。
