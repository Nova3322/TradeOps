## 3. 结果判定

1. immutable manifest 能证明查询使用的是显式、完整、版本化的账户全集，而非偶然已知账户集合。
2. 只有全 scope fresh/confirmed 且 settlement currency 已是 USD 时才产生 USD 组合 MTM。
3. USDT/USDC 不按 1 USD 猜测；缺少认证 FX 事实时明确返回 `FX_FACTS_REQUIRED`。
4. 任一 scope 缺失、Unknown 或 stale 时，整个组合值为 Unknown/null，不暴露局部和。
5. 本包尚未绑定 Risk Engine，也没有真实账户、真实 collector 或真钱资格。
