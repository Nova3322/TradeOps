## 4. 结果判定

1. 已能从同一 current position/protection 事实确定性计算 Mark 回到保护触发价的总损失。
2. Open Heat 与 Protected-Profit Giveback 使用精确余数互斥，18 位金额守恒且不重复抵扣利润。
3. 结果明确属于 scope 的 settlement currency；没有进行未经证据的 USD 或稳定币等值换算。
4. 任一事实未知、错配或数值无效时隐藏全部经济值，不能被解释为零风险。
5. Risk Engine、Risk Ledger、Reservation、Add、scope stress 和调用方 giveback 移除尚未完成；本包不构成
   实盘能力，三项现实能力门仍为 `DISABLED`。
