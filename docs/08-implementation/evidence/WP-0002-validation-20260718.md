## 关键证据

1. 无角色时默认拒绝，拒绝决定与 command receipt、audit、outbox 同事务保存。
2. `PROPOSER + REVIEWER` 多标签不能绕过自审硬门。
3. 独立 Reviewer 对低/中/高风险得到固定 `1 / 1 / 2` quorum 元数据，但数据库不存在 `reviewer_votes`，没有伪造批准事实。
4. 账户/场所/板块/风险档位/动作/渠道作用域不匹配时拒绝。
5. 显式拒绝优先于角色和作用域允许。
6. `SYSTEM_ADMIN` 不继承审核资格；角色撤销影响下一次敏感动作。
7. 动作级 Passkey/WebAuthn 证据精确绑定对象版本、只消费一次；两个并发消费最多一个成功。
8. 动作证据绑定字段不可修改、消费不可逆、撤销不可恢复且历史不能删除。
9. `authorization_decisions` 不能 UPDATE / DELETE。
