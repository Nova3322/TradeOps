# WP-0042 验证证据（2026-07-18）

## 1. 验证范围

- INITIAL `POSITION_RECONCILED` 后唯一冻结 isolated 初始保证金参考额；
- Campaign/Intent/ExecutionFact/PositionSnapshot exact ownership 与 hash 绑定；
- 缺失或零保证金在 ExecutionFact 写入前失败关闭；
- cross margin 未认证归属明确拒绝；
- baseline snapshot hash 自校验、数据库 update/delete 不可变；
- 迁移、schema drift、全量测试、readiness 与现实能力门。

按用户明确约束，未调用、启用或建议 Codex Security，也未使用任何 Codex Security 审计 Skill、插件或模块。


## 5. 结果判定

1. isolated INITIAL 的初始保证金参考额不再依赖后续 UI/current-margin 读数，且每个 Campaign 只能冻结一次。
2. 缺失、零值、scope/hash 不一致或未认证 cross 归属都不能留下部分 POSITION_RECONCILED 事实。
3. 本包只建立 Frozen Return 分母；净收益分子、完整 Campaign PnL 和 `E_campaign` 仍未实现。
4. 所有记录仍为 SHADOW-only，不构成真实 collector、OMS、资金归属或实盘能力认证。
