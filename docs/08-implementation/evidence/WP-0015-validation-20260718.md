## 3. 结果判定

1. 仅 canonical `OPEN` 仓位快照可以证明 `POSITION_RECONCILED`。
2. exact post-intent quantity、scope ownership、时间新鲜度和输入成员关系同时由服务与数据库验证。
3. `FLAT` 与 `UNKNOWN` 保持独立语义，不能伪装为已对账成功。
4. 合法继任 lease 可恢复对账，但不能改变原 claim 或绕过 fencing。
5. 所有 live capability gates 仍为 `DISABLED`，本工作包不构成实盘就绪证明。
