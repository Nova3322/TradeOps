## 5. 结果判定

1. ADD 不再接受 caller `trend_valid`；趋势/回调/策略有效性只能来自 exact immutable evaluation。
2. missing、mismatch、过期、FAIL、UNKNOWN 或 integrity failure 都形成持久化 DENY，不产生新增风险。
3. 评估与最终预检使用同一 Risk Fact Set 和 exact position/protection，且有效期不能被授权窗口放宽。
4. 本包只证明 SHADOW 控制合同和测试 evaluator 夹具，没有实现或认证真实策略 evaluator。
5. `frozen_return_pct` 和 submitted `E_campaign` 仍是明确未关闭的 caller 信任边界。
