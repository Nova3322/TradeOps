## 5. 结果判定

1. opening-only Campaign 现在能把 immutable initial baseline、accepted fill prefix 与 fresh current
   venue position 绑定为一个确定性 hash。
2. 未完成 current position 对账的 ADD fill 会使绑定失败，不会复用旧 quantity/UPNL。
3. exact 数量一致不等于 exclusive ownership；真实唯一订单出口未认证前，UPNL 不升级为 Campaign equity。
4. 本包没有数据库迁移、外部写入口或现实资金能力变化。
