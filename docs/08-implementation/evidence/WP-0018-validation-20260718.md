## 3. 结果判定

1. 账户权益事实只接受完整私有 `VENUE_BALANCES` 输入、精确作用域和冻结外部身份。
2. `UNKNOWN` 经济字段只能是 `NULL`，不会被伪装成零权益或零 UPNL。
3. 应用路径与 PostgreSQL direct-write path 使用同一失败关闭边界。
4. 相同 canonical fact 可以跨 run 重链，但不同经济语义不能复用相同外部身份。
5. 本包只提供场所报告事实，不声称已完成跨币种 MTM、PnL、场所公式认证或真钱能力激活。
