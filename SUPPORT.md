# Support

## Community support

Use repository Discussions or Issues for reproducible questions about local
setup, API integration, documentation, and confirmed defects. Before posting:

- remove tokens, cookies, API keys, wallet material, account IDs, balances,
  Workspace/Team names, database URLs, hostnames, and local paths;
- reproduce with synthetic fixtures and all dangerous gates disabled; and
- include version, platform, commands, expected behavior, and redacted output.

## Security reports

Follow [`SECURITY.md`](SECURITY.md) or contact `SECURITY_EMAIL`. Never open a
public issue containing a suspected vulnerability, credential, live account
detail, or exploit evidence.

## Commercial support and licensing

Closed-source integration, proprietary distribution, SLAs, warranty,
indemnity, managed service, and other negotiated terms require a separate
commercial agreement. Contact `COMMERCIAL_EMAIL`; do not post confidential
terms publicly.

Community support is best effort. No response time or operational guarantee is
created by this document.
